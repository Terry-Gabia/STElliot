# STElliot

TradingView 실시간 데이터 기반 엘리어트 파동 자동 분석기

## 기능

- TradingView 웹소켓으로 실시간 OHLCV 데이터 수집
- 엘리어트 ABC 조정 패턴 자동 감지
- 피보나치 되돌림/확장 레벨 계산
- 이벤트성 갭 급등 자동 감지 (엘파 적용 부적합 종목 필터링)
- 더블바텀 패턴 감지
- 새 상승 임펄스 가능성 감지
- 매수 타이밍 종합 판단

## 지원 시장

| 시장 | 심볼 예시 |
|------|----------|
| 한국 주식 | `005930` (삼성전자), `000660` (SK하이닉스) |
| 한국 지수 | `KOSPI`, `KOSDAQ` |
| 미국 주식 | `NASDAQ:AAPL`, `NASDAQ:NVDA`, `NYSE:TSLA` |
| 암호화폐 | `BINANCE:BTCUSDT`, `BINANCE:ETHUSDT` |

## 설치

```bash
git clone https://github.com/Terry-Gabia/STElliot.git
cd STElliot
pip install -r requirements.txt
```

## 사용법

```bash
# 단일 종목 분석
python elliott.py 005930              # 삼성전자 1시간봉
python elliott.py 000660              # SK하이닉스 1시간봉
python elliott.py KOSPI               # 코스피 지수

# 여러 종목 동시 분석
python elliott.py 005930,000660,KOSPI

# 타임프레임 변경
python elliott.py 005930 --tf 240     # 4시간봉
python elliott.py 005930 --tf D       # 일봉
python elliott.py 005930 --tf 15      # 15분봉

# 해외 주식
python elliott.py NASDAQ:NVDA         # 엔비디아
python elliott.py NASDAQ:AAPL         # 애플

# 암호화폐
python elliott.py BINANCE:BTCUSDT --tf 240  # 비트코인 4시간봉
```

## 출력 예시

```
=================================================================
  005930 엘리어트 파동 분석 (1시간봉)
=================================================================
  현재가: 272,500

  ★ 현재 상태: C파 진행 중

  A파: 299,500 → 262,000 = ▼37,500 (-12.5%)
  B파: 262,000 → 288,500 (되돌림: 70.7%) ✓
  C파: 288,500 → 272,500 = ▼16,000 (C/A: 42.7%)

  C파 피보나치 타겟
  C=0.618A    :      265,325  ▼7,175 (2.6%) ★
  C=A (1:1)   :      251,000  ▼21,500 (7.9%)

  종합 판단
  📉 C파 진행 중 (C/A=43%) — 아직 진행 중
  → 분할매수 준비
```

## 분석 항목

| 항목 | 설명 |
|------|------|
| ABC 구조 | 고점 이후 A파(하락) → B파(반등) → C파(재하락) 자동 감지 |
| B파 되돌림 | 38~78% 정상, 78%+ 과도, 38%- 약함 |
| C파 피보나치 | C=0.618A, C=A(1:1), C=1.272A, C=1.618A |
| 전체 되돌림 | 상승 시작~고점 기준 23.6%, 38.2%, 50%, 61.8%, 78.6% |
| 갭 급등 감지 | 이벤트성 스파이크 자동 필터링 |
| 더블바텀 | A파 저점 재테스트 감지 |
| 새 임펄스 | ABC 완료 후 새 상승 1-2파 가능성 감지 |

## 종합 판단 기준

| C/A 비율 | 상태 | 판단 |
|---------|------|------|
| 0~30% | C파 초기 | 매수 대기 |
| 30~55% | C파 진행 중 | 분할매수 준비 |
| 55~90% | C파 중후반 | 분할매수 시작 가능 |
| 90~115% | C≈A 도달 | 적극 매수 구간 |
| 115%+ | C파 과확장 | 과매도, 확인 후 매수 |

## 주의사항

- 엘리어트 파동 이론은 지수(코스피 등)에 가장 잘 적용됩니다
- 개별 종목은 자체 뉴스/이벤트에 의해 왜곡될 수 있습니다
- 이벤트성 급등(갭 스파이크) 종목은 자동으로 필터링됩니다
- 투자 판단의 참고 자료이며, 투자 손실에 대한 책임은 본인에게 있습니다
